## 📖 Sobre o Projeto

O **Princípio da Informação Consciente (PIC)** propõe que a consciência é uma propriedade fundamental da informação, e que o universo é a dinâmica dessa informação consciente em um processo contínuo de auto-organização e auto-percepção.

A **Teoria do Campo Sinérgico (SFT)** formaliza esse princípio, introduzindo um campo escalar (\(\phi_S\)) que emerge da sinergia local e atua como potencial de coerência.

Este repositório contém o compêndio completo, protocolos experimentais, simulações e arquiteturas de hardware/software baseadas no PIC/SFT.

---

## 🧭 Navegação

- **Fundamentos:** Axiomática, Lagrangiana unificada, equações de sustentação.
- **Protocolos:** H6 (gravidade informacional), H22 (psicodélicos), H32 (biofótons).
- **Simulações:** Código Python para inferência ativa, HPU v2.0, sistema acoplado.
- **Dados:** Séries de HRV da PhysioNet (Fantasia Y1, Y2, O1, O2).
- **Arquitetura:** Especificações para HPU, SFP, HAM, NPS, HI, HRE.
- **Aplicações:** Ética, governança, economia regenerativa, alimentação Miroku.
